# Traditional Chinese Colors

An immersive, fun and synesthetic exploration of a curated palette of traditional Chinese [colors](https://book.douban.com/subject/35166650/).

### Viewing Colors

- **11 Hue Families:** Navigate by color group — from _朱赤_ (Warm Red) to _灰白_ (Neutral).
- **Seasonal Color Viewer:** Navigate colors from each of the 24 solar terms.
- **Fuzzy Search:** Instantly find colors by name (Chinese/Pinyin) or HEX code.
- **Active Color Viewer:** An entire page dynamically displays the selected color's name and a matching classical Chinese poem.

### Exploring Palettes

Six pre-built palettes all made of colors from the book, displayed Mondrian style.

- Harmonious
- Accent
- Balance
- Complementary
- Gradient
- Misty - Author's pick.

Re-build palettes on the fly inside the palette viewer.
