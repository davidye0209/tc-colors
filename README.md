# Traditional Chinese Colors

An immersive, fun and synesthetic exploration of a curated palette of traditional Chinese [colors](https://book.douban.com/subject/35166650/). 

### Viewing Colors

- **11 Hue Families:** Navigate by color group — from _朱赤_ (Warm Red) to _灰白_ (Neutral).
- **Fuzzy Search:** Instantly find colors by name (Chinese/Pinyin) or HEX code.
- **Active Color Viewer:** A banner panel dynamically displays the selected color's name, HEX value, and a matching classical Chinese poem.
- **Seasonal Color Viewer**: A slider panel displays colors from each of the 24 solar terms.

### Exploring Palettes

Six pre-built palettes all made of colors from the book.

- Harmonious
- Accent 
- Balance
- Complementary
- Gradient
- Misty - Author's pick.
